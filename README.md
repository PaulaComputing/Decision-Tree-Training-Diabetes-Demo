# Decision-Tree-Training-Diabetes-Demo
This project demonstrates how to train, evaluate, and optimize a Decision Tree Regressor (DecisionTreeRegressor) to predict diabetes progression using a clinical dataset. It highlights key machine learning concepts such as detecting and preventing overfitting, analyzing feature importance, and tuning hyperparameters using GridSearchCV.
